ARENAS SEM IMAGEM — SF RPG Brasil
=================================

O usuário responde com "<número> + imagem" (arquivo em ~/Downloads ou URL).
Os prompts para gerar cada imagem estão em ~/Downloads/prompts-arenas-sfrpg.md (mesma ordem).

Como processar cada imagem (ver também SKILL.md, seções "Imagens" e "Banco"):
 1. Localize a linha pelo número. Campos: Nº | Personagem | Arena | arquivo sugerido | post(s).
 2. Baixe/copie a imagem para uma pasta nova do scratchpad (URLs da Fandom dão 403:
    peça para o usuário salvar em ~/Downloads).
 3. Converta com scripts/img.py banner (corta letterbox; gera tamanhos 1024/768/300/150)
    usando o nome do arquivo sugerido (sem a extensão + "-arena" já incluso).
 4. Envie para public/wp-content/uploads/AAAA/MM/ (wp_upload_imgs) e confira HTTP 200.
 5. Registre o anexo (wp_posts attachment + _wp_attached_file + _wp_attachment_metadata
    via scripts/wp_meta.py), com post_parent = ID do post.
 6. Em cada post da linha, insira a imagem logo abaixo do parágrafo da seção
    "Arena de ..." (h2/h3), antes da próxima seção/créditos:
      16:9 grande -> <img class="size-large wp-image-ID aligncenter" src=".../x-1024x576.jpg" alt="" width="474" height="267" />
      outros      -> size-full com as dimensões reais (ou size-large reduzido a 474 de largura)
    Não repita uma imagem que o post já mostra ali. Use wp_post_put (confere concorrência).
 7. Quando a linha tiver dois posts (ex.: 57 e 105), use o mesmo anexo nos dois.
 8. Remova a linha deste arquivo (ou marque "[FEITO]") e commite.
